# مسار — كيف تعرضه في المقابلة

## شرح من نصف دقيقة

«بنيت مساحة تعاون للفرق: مساحات عمل، أعضاء، مهام بحالات وأولويات، تعليقات، سجل نشاط وإشعارات داخل التطبيق. كل عملية تمر بفحص عضوية المستخدم وصلاحياته على الخادم، وليس بإخفاء الأزرار فقط.»

## أهم قرار برمجي

مالك المساحة يستطيع إضافة حسابات مسجلة وإسناد مهام إلى الفريق. العضو ينشئ مهام لنفسه ويحدث المهام المسندة إليه. الدور العام admin لا يمنح دخولًا تلقائيًا إلى كل مساحة؛ العضوية هي أساس العزل.

لكل مهمة رقم إصدار. لو فتح شخصان المهمة نفسها وعدّل أحدهما حالتها، يُرفض تحديث الآخر إذا جاء بإصدار قديم برسالة تعارض، بدل أن يضيع التعديل الأول بصمت. يوجد قفل سجل أثناء التحقق والتحديث.

## اعرض هذا السيناريو

افتح المساحة المشتركة بحساب المدير والموظف. أنشئ مهمة للموظف، ثم حدّثها من حسابه وأضف تعليقًا. حساب الضيف لا يستطيع رؤية المساحة حتى يضيفه مالكها. جرب تحديثين بإصدار المهمة نفسه؛ أحدهما يُرفض حتى يعاد تحميل البيانات.

## حدود النسخة

إضافة العضو تتم لحساب موجود داخل التطبيق، دون إرسال بريد. الإشعارات داخل التطبيق فقط وليست Push. لا يوجد تحديث فوري عبر WebSocket، أو حذف أعضاء، أو إرفاق ملفات. زر التحديث يجلب آخر البيانات.
